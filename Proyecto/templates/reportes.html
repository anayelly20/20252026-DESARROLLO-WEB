📑 Reportes en PDF

Selecciona el tipo de reporte y presiona "Generar reporte PDF". El archivo se descargará automáticamente.

Información: Cada reporte incluye título, fecha de generación y datos de la tabla. Si no existen registros, el PDF mostrará un mensaje de No existen registros disponibles para este reporte.
Estructura de tablas disponibles
  • productos: id, nombre, descripcion, precio, cantidad
  • mascotas: id, nombre, especie, raza, edad, propietario, telefono
  • citas: id, mascota_id, fecha, hora, motivo, veterinario, estado
  • historial: id, mascota_id, tipo, descripcion, fecha, veterinario
  • usuarios: id_usuario, usuario
